# 面试准备包

三份材料，面向「AI 产品经理」求职面试。全部基于本项目的真实内容，不是通用模板。

## 三份材料怎么配合用

| 文件 | 页数 | 用途 | 什么时候看 |
| --- | --- | --- | --- |
| `项目三分钟介绍.pdf` | 4 页 | **开口第一件事**：把项目讲清楚 | 面试前最后看一遍 |
| `产品经理方法论面试手册.pdf` | 39 页 | 20 个方法论：定义 · 出处 · 原理 · 公式 + 项目实例 | 提前 1–2 周刷 |
| `AI产品经理技术面试问题大全.pdf` | 38 页 | 122 道技术题：答案要点 + 本项目怎么答 + 追问与陷阱 | 提前 1–2 周刷 |

**建议顺序**：先看《项目三分钟介绍》把主线记住 →
再刷两份题库（先自己想，再看答案）→ 面试当天只看第一份的「速记卡」。

## 三份材料的分工

```
项目三分钟介绍    ← 讲清楚「做了什么、为什么这么做、结果如何」
      │
      ├── 方法论手册  ← 回答「你用什么方法做决策」
      └── 技术手册    ← 回答「你懂不懂技术、能不能和研发对话」
```

面试官的提问基本落在这三个方向。三份材料各自覆盖一个，互不重复。

## 内容特点

**每道题/每个方法都落到本项目**，而不是空讲理论：

- 方法论手册里每个方法都有「本项目怎么用」+「面试示范回答」+「追问与陷阱」
- 技术手册里每题都有「本项目怎么答」，直接对应代码里的真实实现
  （BM25 打分公式、注入检测的 10 条正则、三级降级、三段式输出契约等）
- 三分钟介绍带完整口播稿，可直接背

**为什么这样写**：面试官不考背诵，考的是
「你在什么情况下用它、用它做出了什么决定、它的局限是什么」。
只背定义的回答是 60 分，能讲出取舍和代价的是 90 分。

## 关于数字

文中数字以项目《[需求分析文档](../需求分析文档.md)》为准。
少数标注「示例估算」的是为说明方法而做的演算（如 RICE 评分的假设值），
不是项目的真实测量结果 —— 面试时如果要引用，请说明是估算。

## 重新生成 PDF

`.pdf` 是**生成产物**，源文件是同目录的 `.html`。
改了 HTML 之后重新导出：

```bash
# 在项目根目录执行；需要 frontend/node_modules 里有 playwright
node -e "
const { chromium } = require('playwright');
(async () => {
  const b = await chromium.launch();
  const p = await b.newPage();
  await p.goto('file:///' + process.cwd().replace(/\\\\/g,'/') + '/docs/面试准备/项目三分钟介绍.html');
  await p.pdf({ path: 'docs/面试准备/项目三分钟介绍.pdf', format: 'A4', printBackground: true });
  await b.close();
})();
"
```

或直接用浏览器打开 HTML，`Ctrl+P` → 另存为 PDF（需开启「背景图形」，
否则彩色边框和底色不会打印出来）。
