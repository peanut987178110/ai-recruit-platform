# 墨刀导入包

这份目录里的 `.docx` 是给**墨刀**导入用的。墨刀支持导入 `.docx` / `.md` / `.html` / `.zip`，
其中 `.docx` 保留标题层级与表格的效果最好，所以正式版走 docx。

## 导入方法

墨刀里选择 **导入 → 选择文件**，选对应的 `.docx`。流程图会以图片形式嵌入，
表格保留为可编辑表格。

## 关于线框图

线框图**不在**这个目录，因为墨刀对 `.html` 有专门的导入通道：

```
docs/产品设计/04-线框图.html
```

导入方法：墨刀内「组件 → **HTML转墨刀**」，选择该文件，
会把 20 个页面转成可编辑的墨刀原型。

## 重新生成

`.docx` 是**生成产物**，源文件是同目录上两级的 `.md`。
改了 `.md` 之后，跑一次脚本即可重新生成：

```bash
# 依赖：python-docx（后端虚拟环境里已有）；流程图渲染需要 Node + mermaid-cli
python scripts/md_to_docx.py
```

脚本会：

- 把 Markdown 转成带标题层级、表格、列表的 docx
- 把 ` ```mermaid ` 代码块渲染成 PNG 后嵌入（一张图都没有遗漏）
- 把 `[文字](链接)` 还原成纯文字或真超链接

> **注意**：`.md` 改了但没重跑脚本，这里的 `.docx` 就会过期。
> 如果长期只维护 `.md`，可以把本目录从版本控制里移除，改为按需生成。

## 生成参数

| 项 | 值 | 说明 |
| --- | --- | --- |
| 中文字体 | 微软雅黑 | 不设置的话 Word 会用西文字体渲染汉字 |
| 图片宽度上限 | 6.1 in | 页宽减去页边距 |
| 图片高度上限 | 6.6 in | **必须限制**：只限宽会让竖长流程图超过一页，Word 把它推到下一页，标题孤零零留在上一页 |
| 页边距 | 上下左右各 0.7 in | 收窄以容纳宽表格 |

高度这一条是踩过的坑，记在这里以免改回去。
